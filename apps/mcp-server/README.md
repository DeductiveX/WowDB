# mcp-server

**Status: Planned for v0.4**

This directory is a placeholder for the WowDB MCP (Model Context Protocol) server.

## Planned Tools

| Tool | Description |
|---|---|
| `list_databases` | List available databases for a connection |
| `list_tables` | List tables in a database |
| `describe_table` | Describe columns, indexes and FKs for a table |
| `run_safe_select` | Execute a read-only SELECT via Query Guard |
| `explain_schema` | Summarize a database schema in natural language |
| `generate_documentation` | Generate Markdown docs for a schema |

See [docs/mcp.md](../../docs/mcp.md) for more details.
